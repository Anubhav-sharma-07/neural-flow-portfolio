Principles

Built With Care. Designed to Solve Real Problems.

Start with the goal

Every project begins with what the business needs and who will use the product.

Keep scope honest

Features earn their place. Anything that doesn't serve the goal waits for a later release.

Write code others can maintain

Check on real screens
